A FEW THINGS TO KNOW

Before you press play.

Does StreamGram include movies or shows?

No media library is included. StreamGram finds videos accessible to your connected Telegram account and returns matching streams to Stremio.

Do I need to select channels first?

No. Global search works after connecting your account. Select folders or channels only if you want them to appear as browsable catalogs.

What do I need to self-host?

An always-on server with a public HTTPS URL, Telegram API credentials, a TMDB token, and your Telegram account. The browser wizard guides you through setup; GitHub has the full instructions.

How does the one-week trial work?

The trial button opens our hosted instance. Follow the instructions there to join. Signup and access are managed on that instance; this page does not create an account.

Can I change the language?

Yes. This page and the StreamGram dashboard support English, Hebrew, Russian, and Arabic. Your search language is a separate preference inside StreamGram.

Where can I get help?

Join the Telegram community for discussion and support. For source code, deployment instructions, and issue reports, visit the GitHub repository.
